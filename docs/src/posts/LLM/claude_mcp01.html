1 기본 개념

1.1 요약

  • Claude는 모델(두뇌),
  • MCP는 그 모델이 바깥 세상(파일, DB, 장비, 웹서비스)과 대화하는 표준 규약(USB-C 같은 거),
  • agent는 모델이 그 도구들을 써서 스스로 판단하며 여러 단계를 돌리는 루프.

셋을 다 익히면 예를 들어 - Claude가 내 데이터 디렉토리를 읽고 실험결과를 파싱해서 plot까지 만들어 오는” 흐름이 가능해짐.

1.2 조금 더 상세하게

  • MCP(Model Context Protocol)는 “tool server”를 만드는 방식이야. Python으로 보면 함수 몇 개에 데코레이터 붙이면 끝. 예를 들어 @mcp.tool() 아래에 def read_mcstas(path: str) -> dict: 를 정의하면 Claude가 그 함수의 이름, docstring, type hint 를 보고 “아, 이 도구를 지금 써야겠다”고 판단해서 호출해. 서버는 stdio 나 HTTP 로 뜨고, Claude Desktop이나 Claude Code가 client 역할. 핵심은 모델이 코드를 실행하는 게 아니라, 모델이 “이 함수를 이 인자로 불러줘”라고 요청하면 client가 실제로 실행하고 결과를 돌려주는 구조라는 것. 그래서 안전성 경계가 명확해.

  • Agent는 그 위에서 도는 loop야. 모델이 생각 → 도구 호출 → 결과 관찰 → 다시 생각… 을 목표가 달성될 때까지 반복해. Claude Code가 바로 그 agent이고, Agent SDK를 쓰면 직접 Python으로 그런 loop를 짜서 자기 workflow에 맞춘 agent를 만들 수도 있어. 지금 이 대화창에서 내가 Bash 돌리고 파일 읽는 것도 같은 구조야.

물리학자 관점으로 비유하면, MCP는 장비 driver/API이고, agent는 그 driver들을 묶어서 측정 sequence를 자동으로 돌리는 실험 제어 스크립트 — 단지 sequence가 hard-coded가 아니라 모델이 매 step 판단한다는 게 차이.

2.1 uv init --no-workspace

uv init --no-workspace 명령어는 현재 디렉터리가 부모 폴더의 워크스페이스(Workspace)에 자동으로 포함되는 것을 방지하고, 독립된 단일 파이썬 프로젝트로 초기화할 때 사용한다.

주요 특징 및 동작 방식

  • 부모 pyproject.toml 무시: 상위 디렉터리에 워크스페이스 설정이 있더라도 이를 탐색하거나 종속시키지 않고 현재 폴더를 독립적인 루트로 처리한다.
  • 사용 목적:
    • 상위 폴더에 있는 워크스페이스 설정 때문에 발생하는 에러(No project table found... 등)를 우회할 때,
    • 모노레포(Monorepo) 구조나 워크스페이스의 일부가 아닌, 완전히 분리된 일반 프로젝트를 만들고 싶을 때.

2.2 uv add "mcp[cli]"

uv add "mcp[cli]" 명령어는 Python 패키지 관리자인 uv 를 사용하여 Anthropic의 MCP Python SDK를 CLI 개발 도구와 함께 프로젝트에 추가하는 명령어. 이 명령어가 실행하는 핵심 역할과 개발 흐름에서의 의미는 다음과 같다.

주요 역할

  • mcp 패키지 설치: LLM(대형 언어 모델)이 로컬 도구나 데이터에 접근할 수 있도록 돕는 MCP 서버/클라이언트 구축 라이브러리를 추가한다.
  • [cli] 엑스트라(Extra) 포함: MCP 개발 및 디버깅에 필수적인 mcp 명령어 인터페이스를 활성화한다.
  • 의존성 자동 관리: 프로젝트의 pyproject.toml 및 uv.lock 파일에 해당 패키지를 기록하고 가상환경(.venv)에 즉시 반영한다.

앞서 uv init --no-workspace 에서 생성된 파일 이외에 .venv 폴더와 uv.lock 파일이 추가된다.

이 명령어를 사용하는 핵심 이유: mcp dev

[cli] 패키지가 설치되면 터미널에서 MCP Inspector를 실행할 수 있는 mcp dev 도구를 사용할 수 있다.

# MCP 서버 코드(예: server.py)를 작성한 후 Inspector 실행
uv run mcp dev server.py
  • 이 명령어를 실행하면 웹 브라우저 환경의 대화형 UI(Inspector)가 열린다.
  • LLM에 연결하기 전에 내가 만든 MCP Tool, Resource, Prompt가 올바르게 작동하는지 안전하게 테스트할 수 있다.

5 MCP Primitives

MCP 프리미티브(Primitives)는 MCP 환경에서 AI 모델(LLM)이 외부 세계(데이터, 도구, 작업 절차 등)와 안전하게 소통하기 위해 사용하는 가장 기본적이고 표준화된 3대 빌딩 블록을 뜻한다. 과거에는 AI에게 기능을 부여할 때 개발자가 일일이 커스텀 함수(Function Calling)로 포장해야 했지만, MCP는 이를 도구(tools), 자원(resources), 프롬프트(prompts) 라는 3가지 기본 primitives 로 정형화하여 관리한다. 각 프리미티브를 구분하는 가장 핵심적인 기준은 바로 누가 이것을 제어하는가(제어 주체) 이다.

5.1 도구, 자원, 프롬프트

1. 🛠️ Tools (도구) — 모델 제어

AI 모델이 능동적으로 판단하고 직접 실행하는 기능.

  • 제어 주체: AI 모델 (LLM)
  • 설명: 모델은 사용자의 질문을 분석하고, 필요한 경우 서버가 열어둔 도구를 스스로 선택해 파라미터를 채워 호출한다. 텍스트 답변을 넘어서 실제 행동(Action)을 취하는 영역.
  • 예시: 웹 검색하기(search), 이메일 발송하기(send_email), 데이터베이스에 레코드 추가하기, 계산기 실행 등.
  • 보안: 시스템에 직접적인 변경(부수 효과)을 일으킬 수 있으므로, 실행 전 사람의 승인(Human-in-the-loop) 단계를 두어 통제할 수 있다.

2. 🗄️ Resources (리소스) — 애플리케이션 제어

AI 모델이 올바른 답변을 생성할 수 있도록 제공되는 안전한 읽기 전용 데이터.

  • 제어 주체: AI 애플리케이션 (Host App)
  • 설명: 파일 내용, 로그, 데이터베이스 조회 결과 등 모델이 읽을 수 있는 데이터 컨텍스트. 리소스는 읽기 전용(Read-only)이므로 모델이 임의로 데이터를 수정하거나 시스템 상태를 변경할 위험이 없다.
  • 예시: 로컬 소스 코드 파일 읽기, 회사 규정 문서 제공, 서버 에러 로그 파일 가져오기 등.

3. 📝 Prompts (프롬프트) — 사용자 제어

특정 작업이나 워크플로우를 위해 서버에 미리 정의해 둔 고품질의 프롬프트 템플릿.

  • 제어 주체: 사용자 (User)
  • 설명: 사용자가 매번 긴 지시사항을 직접 타이핑할 필요 없이, 서버가 제공하는 템플릿을 선택해 필요한 변수(매개변수)만 입력하면 정형화된 프롬프트가 모델에 주입된다.
  • 예시: “이 코드를 리뷰해 줘”, “버그 리포트를 바탕으로 깃허브 이슈 양식을 작성해 줘” 같은 미리 짜인 협업 워크플로우 템플릿.

한눈에 보는 프리미티브 비교

프리미티프 제어 주체 성격 주요 동작 예시 핵심 목적
Tools AI 모델 쓰기/실행 가능 (액션) API 호출, 파일 수정, 명령 실행 모델의 능동적 실행력 확장
Resources 애플리케이션 읽기 전용 (데이터) 파일 내용, DB 읽기, 실시간 로그 안전한 컨텍스트 데이터 제공
Prompts 사용자 입력/선택 (템플릿) 코드 리뷰 양식, 번역 템플릿 정형화된 워크플로우 지원

5.2 Primitive 분리 이유

MCP가 이러한 구조를 채택한 이유는 안전성과 조합 가능성(Composability) 때문이다. 과거처럼 모든 것을 ‘함수(Function)’ 하나로 뭉뚱그리면 AI가 실수로 중요 데이터를 삭제하는 등의 위험이 있다. 반면 MCP는 데이터(Resources)는 안전하게 읽기만 하되, 동작(Tools)이 필요할 때만 명확한 권한 아래 실행하고, 작업(Prompts)은 템플릿화하여 AI 에이전트가 보다 체계적이고 신뢰성 높게 행동하도록 만든다.

6 첫 MCP server

"""
첫 MCP server (mcp >= 2.0): tool / resource / prompt 세 primitive 전부 포함.
 
  uv run mcp dev stats_server.py      # Inspector로 테스트
  uv run stats_server.py              # stdio로 직접 실행 (Claude Desktop이 이 방식으로 띄움)
"""
 
import json
import math
import statistics
from mcp.server.mcpserver import MCPServer  # mcp>=2.0 (1.x에서는 mcp.server.fastmcp.FastMCP)
 
mcp = MCPServer("stats")
 
# ---------------------------------------------------------------------------
# 가짜 "데이터 저장소". 실제라면 파일이나 DB에서 읽어올 자리.
# ---------------------------------------------------------------------------
DATASETS = {
    "co60_peak": {
        "description": "Co-60 1332 keV peak centroid, 5 repeated fits (keV)",
        "values": [1332.4, 1332.6, 1332.3, 1332.7, 1332.5],
        "errors": [0.2, 0.3, 0.2, 0.4, 0.2],
    },
    "beam_flux": {
        "description": "Thermal neutron flux at sample, 4 monitor runs (1e7 n/cm2/s)",
        "values": [1.02, 0.98, 1.05, 1.01],
        "errors": [0.03, 0.05, 0.02, 0.03],
    },
}
 
 
# ---------------------------------------------------------------------------
# TOOLS — 모델이 호출하는 "동사"
# ---------------------------------------------------------------------------
@mcp.tool()
def describe(values: list[float]) -> dict:
    """Compute basic descriptive statistics of a list of numbers.
 
    Returns count, mean, standard deviation (sample), min, max, median,
    skewness (g1 = m3 / m2^1.5) and excess kurtosis (g2 = m4 / m2^2 - 3),
    where m_k are central moments with 1/n normalization.
    skewness and kurtosis are None when all values are equal (m2 = 0).
    Use this whenever the user gives you a set of numbers and wants a summary.
    """
    if len(values) == 0:
        raise ValueError("values must not be empty")
    n = len(values)
    mean = statistics.fmean(values)
    m2 = sum((v - mean) ** 2 for v in values) / n
    m3 = sum((v - mean) ** 3 for v in values) / n
    m4 = sum((v - mean) ** 4 for v in values) / n
    return {
        "n": n,
        "mean": mean,
        "std": statistics.stdev(values) if n > 1 else 0.0,
        "min": min(values),
        "max": max(values),
        "median": statistics.median(values),
        "skewness": m3 / m2**1.5 if m2 > 0 else None,
        "kurtosis": m4 / m2**2 - 3.0 if m2 > 0 else None,
    }
 
 
@mcp.tool()
def weighted_mean(values: list[float], errors: list[float]) -> dict:
    """Inverse-variance weighted mean of measurements with 1-sigma errors.
 
    values: measured values
    errors: corresponding 1-sigma uncertainties (same length, all > 0)
    Returns the weighted mean, its uncertainty, and chi2/dof as a consistency check.
    """
    if len(values) == 0:
        raise ValueError("values must not be empty")
    if len(values) != len(errors):
        raise ValueError("values and errors must have the same length")
    if any(e <= 0 for e in errors):
        raise ValueError("all errors must be positive")
    w = [1.0 / e**2 for e in errors]
    sw = sum(w)
    mean = sum(wi * v for wi, v in zip(w, values)) / sw
    err = math.sqrt(1.0 / sw)
    dof = len(values) - 1
    chi2 = sum(((v - mean) / e) ** 2 for v, e in zip(values, errors))
    return {
        "mean": mean,
        "error": err,
        "chi2": chi2,
        "dof": dof,
        "chi2_per_dof": chi2 / dof if dof > 0 else None,
    }
 
 
# ---------------------------------------------------------------------------
# RESOURCES — 모델이 읽기만 하는 "명사". URI로 지정.
# ---------------------------------------------------------------------------
@mcp.resource("stats://datasets")
def list_datasets() -> str:
    """Index of available datasets (name + one-line description)."""
    index = {name: d["description"] for name, d in DATASETS.items()}
    return json.dumps(index, indent=2)
 
 
# {name} 부분이 변수인 "resource template". stats://dataset/co60_peak 처럼 읽음.
@mcp.resource("stats://dataset/{name}")
def get_dataset(name: str) -> str:
    """Raw values and 1-sigma errors of one dataset, as JSON."""
    if name not in DATASETS:
        raise ValueError(f"unknown dataset '{name}'. See stats://datasets")
    return json.dumps(DATASETS[name], indent=2)
 
 
# ---------------------------------------------------------------------------
# PROMPTS — 사람이 고르는 "미리 짜둔 지시문". 반환값이 곧 user message가 됨.
# ---------------------------------------------------------------------------
@mcp.prompt()

6.1 @mcp.tool()

@mcp.tool 데코레이터는 MCP 서버를 구축할 때, 특정 파이썬 함수를 AI 모델(LLM)이 호출할 수 있는 ’도구(Tool)’로 등록하는 역할을 한다. 주로 Python용 MCP SDK(mcp.server.fastmcp 등)에서 사용되며, 이 데코레이터를 붙이면 함수의 이름, 설명, 매개변수 타입이 AI 모델에 자동으로 전달된다.

주요 특징 및 규칙

  • 자동 문서화: 함수의 독스트링(Docstring)은 AI 모델이 이 도구를 ‘언제, 어떻게 사용해야 하는지’ 이해하는 설명서가 되므로 반드시 명확하게 작성해야 한다.
  • 타입 힌트 필수: 매개변수와 반환값의 타입 힌트(Type Hints)를 기반으로 AI가 전달할 인자의 형식을 파악한다. (str, int, float 등)
  • 다양한 활용: 웹 크롤링, 로컬 파일 읽기/쓰기, 데이터베이스 조회, 외부 API 호출 등 AI의 능력을 확장하는 다양한 기능을 도구로 만들 수 있습니다.

6.2 @mcp.resource("...")

@mcp.resource("...") 는 MCP 서버를 구현할 때 특정 데이터나 텍스트 리소스를 LLM에 제공하기 위해 선언하는 데코레이터이다. 기존 웹 개발의 라우터(예: FastAPI의 @app.get("/items")) 와 유사한 개념으로, LLM이 읽을 수 있는 파일, 로그, 프롬프트 템플릿 등의 정적/동적 자원을 데코레이터 아래의 함수를 통해 노출시킨다니다.

특징

  • 목적: AI 모델(Client)이 MCP 서버로부터 컨텍스트(데이터, 문서, 설정 등)를 조회할 수 있는 주소(URI)를 맵핑한다.
  • 주요 인자: URI 표준 스키마(예: file://…, custom://…) 형식을 문자열로 전달한다.

추가 설명

@mcp.resource("stats://dataset/{name}") 나 @mcp.resource("stats://datasets") 같은 데코레이터 형식에 대해 질문함.

[Answer from claude] 질문 답부터: stats://datasets 는 URI야. https://example.com/page 랑 같은 문법이고, stats는 scheme, datasets는 path. MCP가 정한 키워드는 하나도 없어 — stats도 datasets도 내가 그냥 지어낸 이름이야. 서버 이름(MCPServer("stats"))과 같게 쓴 건 순전히 보기 좋으라고 한 거고, foo://bar 라고 써도 똑같이 동작해.

MCP 규약이 요구하는 건 딱 하나야: resource는 각각 고유한 URI로 식별된다. client가 resources/list를 호출하면 서버가 URI 목록을 주고, client가 resources/read에 그 URI를 넣어 보내면 서버가 내용을 돌려줘. 그러니까 URI는 “resource의 이름표”이고, 모양이 URL처럼 생긴 건 파일(file:///...)이나 웹(https://...)처럼 이미 URI를 쓰는 자원과 한 체계로 다루기 위해서야. 실제로 filesystem 서버는 file:// scheme을 쓰고, 자기만의 데이터를 노출하는 서버는 보통 자기 이름을 scheme으로 써. 관례일 뿐 규칙은 아니야.

mime type은 별도야. @mcp.resource(...) 에 mime_type="application/json" 같은 인자를 따로 줄 수 있고, 안 주면 반환형이 str 이면 text/plain, bytes 면 application/octet-stream 으로 잡혀. 내 코드에선 JSON 문자열을 돌려주면서 mime type을 안 적었으니 엄밀히는 application/json 을 명시해 주는 게 더 올바르긴 해.

그리고 stats://dataset/{name} 의 {name} 이 변수인 것도 MCP의 “resource template”이라는 개념이긴 한데, 그 문법({})은 MCP가 새로 만든 게 아니라 RFC 6570 URI Template이라는 기존 표준이야. 여기서도 MCP는 기존 웹 표준을 그대로 빌려 쓰는 쪽을 택했어.

6.3 @mcp.prompt()

@mcp.prompt() 는 MCP 서버에서 재사용 가능한 프롬프트 템플릿을 정의할 때 사용하는 Python 데코레이터이다. FastMCP 등의 프레임워크를 사용할 때, 일반 Python 함수 위에 @mcp.prompt() 를 선언하면 해당 함수가 MCP Prompts 프리미티브로 등록되어 클라이언트(예: Claude Desktop, Cursor 등)가 호출할 수 있는 슬래시 명령어(/)나 템플릿 형태로 노출된다.

핵심 요약 및 동작 메커니즘

  • 사용자 중심 제어: AI 모델이 판단하여 자동으로 실행하는 Tools와 달리, Prompts는 사용자가 UI에서 명시적으로 선택하여 실행하는 구조화된 대화 시작점(Conversation Starter)이다.
  • 프롬프트의 분업화: 복잡한 프롬프트 엔지니어링 지식이나 도메인 규칙을 서버 측에 캡슐화(정의)해두고, 클라이언트는 세부 구현을 모른 채 인자(Arguments)만 넘겨 고품질의 프롬프트 결과를 얻는다.
  • 컨텍스트 결합: 프롬프트가 실행될 때 단순히 텍스트만 반환하는 것이 아니라, 서버 내의 특정 데이터(Resources)나 파일 내용을 동적으로 읽어와 메시지 배열에 함께 삽입할 수 있다.

7 claude mcp add-from-claude-desktop

  • Desktop 앱의 claude_desktop_config.json 에 등록해 둔 MCP 서버 설정을 Claude Code 쪽 설정으로 복사해 오는 명령어이다.
  • Claude code 와 Claude desktop 은 설정 파일을 공유하지 않는다.
    • Desktop은 그 JSON,
    • Claude Code는 ~/.claude.json이나 프로젝트의 .mcp.json
  • 복사라는 게 중요하다. 실행 중인 서버를 공유하는 게 아니라, “uv --directory ... run mcstas_server.py로 띄워라” 라는 레시피를 가져오는 거라서 Claude Code는 자기 프로세스를 따로 운다. 그래서 Desktop과 Claude Code를 동시에 켜두면 같은 서버 코드가 두 번 돌게 된다.
    • 복사 시점 이후에 Desktop 쪽 설정을 바꾸면(예: MCSTAS_ROOT 경로 수정) Claude Code에는 반영 되지 않으므로 다시 import 하거나 claude mcp remove mcstas 후 재등록해야한다.
  • Desktop을 거치지 않고 Claude Code에 직접 등록할 수도 있어:
claude mcp add --scope user mcstas \
  -e MCSTAS_ROOT=/Users/jiyong/CG4A -e MCSTAS_PLOT_DIR=/Users/jiyong/mcstas-plots \
  -- /usr/local/bin/uv --directory /Users/jiyong/mcstas-mcp run mcstas_server.py

--scope user 로 하면 어느 폴더에서 claude를 열어도 보이고(지금 import 한 건 local scope라 ~/mcp-play 에서만 보인다), --scope project 로 하면 그 폴더에 .mcp.json 이 생겨서 git 에 넣고 동료와 공유할 수 있다. 등록된 것 확인은 claude mcp list, 제거는 claude mcp remove <이름>.
