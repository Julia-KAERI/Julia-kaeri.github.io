1.2 핵분열 반응

  • 반응식 : \(\boxed{{}^{235}\text{U} + n \longrightarrow \text{X} + \text{Y} + 2 \sim 3 \, n + 200 \text{ MeV}}\)
  • 핵분열 에너지 : 200 Mev/fission \(\approx\) 3.2x10-11 J/fission.
    • 30 MW \(\approx\) 1018 fisson/sec.
    • 원자력 발전소의 경우 : ~ 1020 fission/sec.


2 중성자 발생 반응

  • Alpha-induced reactions (RaBe, PoBe, AmBe, …)
    • \(^9\text{Be}(\alpha,\, n) {}^{12} \to \text{C} + \text{5.7 MeV}\) (Neutron yield : 15 x 106 n/s/Ci)
  • Spontaneous fission (252Cf)
    • \(^{252}\text{Cf}(\text{sf}) \to {}^{134}\text{Te} + {}^{115}\text{Pd} + 3n + \text{212 MeV}\) (Neutron yield : 4.4 x 109 n/s/Ci (2.4 x 1012 n/s/g)
  • Neutron-induced fission (HANARO, Power reactors)
    • \({}^{235}\text{U}(n,f) \to {}^{134}\text{Te} + {}^{99}\text{Zr} + 3n + \text{185 MeV}\)
  • Fusion reactions (neutron generators, KSTAR, ITER)
    • \(d(d,n) \to {}^{3}\text{He} + \text{3.3 MeV}\), \(t(d,n) \to {}^{4}\text{He} + \text{17.6 MeV}\).


3 중성자 검출 반응

  • \(n + {}^{3}\text{He} \longrightarrow {}^{3}\text{H} + {}^{1}\text{H} + \text{0.764 MeV}\).

  • \(n + {}^{6}\text{Li} \longrightarrow {}^{4}\text{He} + {}^{3}\text{H} + \text{4.79 MeV}\).

  • \(\begin{array}{rl} n + {}^{10}\text{B} &\longrightarrow {}^{7}\text{Li}^\ast + {}^{4}\text{He} \\[0.3em] &\longrightarrow {}^{7}\text{Li} + {}^{4}\text{He} + 0.48\gamma + \text{2.3 MeV (93\%)}\\[0.3em] &\longrightarrow {}^{7}\text{Li} + {}^{4}\text{He} + \text{2.8 MeV (7\%)}\end{array}\).

  • \(n + {}^{155}\text{Gd}\longrightarrow \text{Gd}^\ast + \gamma-ray \longrightarrow \textbf{conversion electron}\).

  • \(n + {}^{157}\text{Gd} \longrightarrow \text{Gd}^\ast + \gamma-ray \longrightarrow \textbf{conversion electron}\).

  • \(n + {}^{235}\text{U} \longrightarrow \text{fission fragments} + \sim \text{160 MeV}\).

  • \(n + {}^{239}\text{Pu} \longrightarrow \text{fission fragments} + \sim \text{160 MeV}\).


4 중성자 영상 검출 소재

  • ZnS:6LiF
    • \(n + {}^{6}\text{Li} \longrightarrow {}^{4}\text{He} + t + \text{~5 MeV}\).
    • Resolution from 150 µm to 300 µm,
    • Thermal stopping power of 20%
    • High light yield (105 photons / neutron)
  • GadOx (Gd2O2S:Tb)
    • \(\text{Gd} + n \longrightarrow e^-\) , energy ≤ 71 keV per neutron capture on average
    • Resolution ~10-20 µm
    • Thermal stopping power up to 80%
    • Low light yield (103 photons / neutron)
